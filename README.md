# PulsarUI

**PulsarUI** is a modern, lightweight UI framework built with **C** and **SDL2**.

![PulsarUI](https://github.com/user-attachments/assets/9fc31909-ca23-4a15-92d2-386eaf7dcdec)

## Features

* Written in C
* Built on SDL2
* Lightweight and fast
* Modern UI design
* Simple Makefile-based build system

## Requirements

* C compiler
* Make
* SDL2
* SDL2_ttf

## Installation

### Arch Linux

Install the required dependencies:

```bash
sudo pacman -S sdl2 sdl2-ttf
```

### Debian / Ubuntu

Update your package lists and install the required dependencies:

```bash
sudo apt-get update
sudo apt-get install libsdl2-dev libsdl2-ttf-dev
```

## Build

Clone the repository:

```bash
git clone https://github.com/ggg610523-lab/pulsar-ui
cd pulsar-ui
```

Build the project using the Makefile:

```bash
make
```

## Running

After building, run the generated executable:

```bash
./liquid_glass
```

> The executable name may vary depending on the project's Makefile configuration.
